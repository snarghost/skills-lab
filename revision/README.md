# Méthode de révision

## 1. Flashcards Anki (quotidien, 10 min)
- Installer Anki (PC) et AnkiDroid ou AnkiMobile, synchronisés via un compte AnkiWeb gratuit.
- Importer `anki/<techno>.csv` (Fichier > Importer). Les lignes `#` en tête configurent l'import automatiquement.
- Un paquet par parcours, ou un paquet unique filtré par tags (`zabbix::module03`).
- Anki gère la répétition espacée : il suffit de faire les cartes du jour.

## 2. Fiches (hebdomadaire, 15 min)
- Relire la `fiche-revision.md` d'un parcours terminé, en tournant.

## 3. Quiz Claude (toutes les 2 semaines)
- Dans le projet Claude, commande « révision ». Noter les erreurs dans `progression.md`, section « Points faibles ».

## 4. Rebuild challenge (mensuel)
- Repartir d'une machine propre, cloner le dépôt, relancer un lab sans regarder les notes, puis comparer.
- C'est la révision la plus efficace : elle entretient les automatismes et teste la documentation.
